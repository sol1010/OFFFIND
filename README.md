# OFFFIND

**Windows 파일·폴더 검색 + Excel/PDF 내용 검색**

파일 이름부터 문서 안의 행·페이지까지 한 검색창에서 찾습니다.

OFFFIND는 사용자가 지정한 폴더를 미리 색인해 두고, 전역 단축키로 검색창을 바로 띄워 검색하는 Windows용 검색 도구입니다.

핵심은 두 가지입니다.

- **파일명만 검색** — 폴더 안의 모든 파일과 하위 폴더 이름을 빠르게 검색
- **내용까지 검색** — Excel은 시트·행 단위, PDF는 페이지 단위로 내용을 검색

폴더마다 검색 방식을 따로 지정할 수 있기 때문에, `C:\`처럼 파일 수가 많은 곳은 파일명만 색인하고 문서 폴더만 내용 검색 대상으로 두는 식으로 사용할 수 있습니다.

## 주요 기능

### 파일·폴더 이름 검색

`파일명만 검색` 모드는 문서 내용을 열어 읽지 않고 **파일과 폴더 이름 자체를 색인**합니다.

- 확장자 제한 없이 모든 파일명을 검색
- 하위 폴더 이름도 검색 결과에 표시
- 큰 폴더나 드라이브 전체를 검색 대상으로 지정 가능
- 파일을 더블클릭하거나 `Enter`를 누르면 바로 실행
- 검색 결과를 `폴더 / PDF / 엑셀 / 기타`로 나눠 표시

새로 추가한 검색 폴더는 기본적으로 `파일명만 검색` 모드로 설정됩니다.

### Excel / PDF 내용 검색

내용 검색이 필요한 폴더만 `내용까지 검색`으로 지정할 수 있습니다.

현재 지원 형식:

- `.xlsx`
- `.xlsm`
- `.pdf`

Excel은 **시트의 각 행**, PDF는 **각 페이지**를 하나의 검색 단위로 색인합니다.

예를 들어 검색 결과가 단순히 `업무보고서.xlsx`라고만 나오지 않고:

```text
업무보고서.xlsx                    요약 · 42행
... 2분기 예산 검토 및 일정 조정 내용 ...
```

처럼 실제 검색 위치와 주변 내용을 함께 보여줍니다.

검색어와 일치한 부분은 결과 내용에서 강조 표시됩니다.

### 검색된 위치로 바로 열기

내용 검색 결과는 가능하면 파일만 여는 데서 끝나지 않고 **검색된 위치로 바로 이동**합니다.

- Excel — 해당 시트와 행으로 이동
- PDF — 해당 페이지로 이동

PDF 페이지 이동을 지원하는 기본 뷰어:

- Microsoft Edge
- Adobe Acrobat / Reader
- SumatraPDF
- Foxit Reader

지원되지 않는 PDF 뷰어이거나 위치 이동에 실패해도 파일 자체는 기본 프로그램으로 열립니다.

### 여러 검색 폴더 관리

검색 대상 폴더는 여러 개 추가할 수 있습니다.

각 폴더마다 다음을 별도로 설정할 수 있습니다.

- 표시 이름
- `파일명만 검색` / `내용까지 검색`
- 검색창에서 포함 / 제외

여러 폴더를 하나의 **그룹**으로 묶을 수도 있습니다. 그룹은 검색창에서 하나의 폴더 칩으로 표시되고, 결과에서는 실제 출처 폴더까지 다시 구분해서 보여줍니다.

검색창 하단의 폴더 칩을 클릭하면 해당 폴더를 현재 검색에서 즉시 포함하거나 제외할 수 있습니다.

### 빠르게 띄우는 검색창

- 기본 전역 단축키: `Ctrl+Space`
- 트레이 아이콘으로도 열기 가능
- 검색창은 결과가 생기면 현재 위치를 기준으로 위쪽으로 확장
- 창 위치와 너비 기억
- 좌우 가장자리 드래그로 너비 조절
- 항상 위에 표시 설정
- 투명도 조절
- 파일명/내용 텍스트 크기 조절
- 내용 미리보기 줄 수 조절
- Windows 시작 시 자동 실행

### 검색 방식

검색은 **2글자 이상**부터 시작합니다.

공백으로 여러 단어를 입력하면 모든 단어가 포함된 결과만 표시합니다. 단어 순서는 상관없습니다.

```text
보고서 예산
```

이라면 `보고서`와 `예산`을 모두 포함한 결과를 찾습니다.

키보드 조작:

- `↑` / `↓` — 결과 이동
- `Enter` — 선택한 파일 또는 검색 위치 열기
- `Esc` — 검색창 닫기

한글 IME 조합 중인 글자도 반영해 검색이 한 박자 늦게 갱신되는 현상을 줄였습니다.

검색 결과는 최대 5,000개까지 표시하며, 결과 목록은 화면에 보이는 행만 그리는 방식으로 구성되어 많은 결과에서도 UI 생성 비용을 줄였습니다.

## 색인 방식

OFFFIND는 검색할 때마다 디스크 전체를 처음부터 읽는 대신 색인을 만들어 사용합니다.

### 파일명만 검색

파일명 검색 폴더는 `os.scandir()` 기반으로 순회하며 **파일별 `os.stat()`이나 문서 파싱을 하지 않습니다.**

즉 파일명과 폴더명을 수집하는 데 필요한 작업만 수행합니다.

### 내용까지 검색

Excel/PDF 내용 검색 폴더는 파일의 수정시간과 크기를 캐시에 저장합니다.

변경되지 않은 파일은 다시 파싱하지 않고, 변경된 파일만 다시 읽습니다.

### 자동 갱신

색인은 백그라운드 스레드에서 실행됩니다.

다음 시점에 자동 갱신됩니다.

- 프로그램 시작 시
- 검색창을 열 때
- 5분마다

트레이 메뉴의 `지금 색인 새로고침`으로 수동 갱신할 수도 있습니다.

현재는 실시간 파일시스템 감시가 아니라 **주기적으로 폴더를 다시 확인하는 방식**입니다. 따라서 방금 생성한 파일은 다음 갱신 전까지 검색되지 않을 수 있습니다.

색인 캐시는 다음 위치에 저장됩니다.

```text
%APPDATA%\OFFFIND\index_cache.json
```

설정은 다음 위치에 저장됩니다.

```text
%APPDATA%\OFFFIND\settings.json
```

## 다운로드

Python 설치 없이 사용할 수 있습니다.

**[Releases 페이지에서 최신 버전 받기](https://github.com/sol1010/OFFFIND/releases/latest)**

- `OFFFIND-Setup.exe` — 설치 프로그램
- `OFFFIND-portable.zip` — 압축 해제 후 바로 실행

설치 프로그램은 사용자 폴더에 설치되며 관리자 권한이 필요하지 않습니다.

## 개발용 실행

```bash
pip install -r requirements.txt
pythonw main.py
```

콘솔을 같이 보려면:

```bash
python main.py
```

주요 의존성은 PySide6, openpyxl, pdfplumber, keyboard, pywin32입니다.

## exe 빌드

```bash
pip install -r requirements.txt
build_exe.bat
```

빌드 후:

```text
dist\OFFFIND\OFFFIND.exe
```

가 생성됩니다. PyInstaller `--onedir` 방식이므로 생성된 폴더 전체를 함께 사용해야 합니다.

## 설치 프로그램 빌드

exe를 먼저 빌드한 뒤 [Inno Setup](https://jrsoftware.org/isinfo.php)으로 `installer.iss`를 컴파일합니다.

```bash
build_exe.bat
"경로\ISCC.exe" installer.iss
```

## 알려진 제약

- 구버전 Excel `.xls` 형식은 현재 검색 대상이 아닙니다.
- 이미지로만 이루어진 PDF처럼 텍스트 레이어가 없는 문서는 내용 검색이 되지 않습니다.
- `내용까지 검색`은 현재 `.xlsx`, `.xlsm`, `.pdf`만 지원합니다.
- 전역 단축키는 관리자 권한으로 실행 중인 다른 프로그램에 포커스가 있을 때 동작하지 않을 수 있습니다.
- 파일 변경사항은 실시간 감시가 아니라 다음 자동/수동 색인 시 반영됩니다.
